# LONELY-EU D3.2: data quality assessment and harmonisation of loneliness measures

The open-science bundle of Deliverable 3.2 of LONELY-EU (Horizon Europe, Grant
Agreement 101177225), University of Milan. The same README sits in all three places below,
so a reader who lands on any of them reaches the other two.

| Component | Where | What it holds |
|---|---|---|
| Preregistration | OSF, https://doi.org/10.17605/OSF.IO/NK2ZX | The frozen analysis plan, never edited after registration |
| Archive | Zenodo, https://doi.org/10.5281/zenodo.23769106 | The protocol with its appendices; later the report and its aggregate results |
| Code | GitHub, https://github.com/arturobertero/LONELY-EU_D3.2 | The analysis code; every release is archived on Zenodo with its own DOI |

**Data.** No microdata of the 20 surveys, raw or cleaned, are deposited anywhere in this
bundle. Each producer licenses its data to named researchers; Appendix A of the protocol
says where to apply. The public record holds aggregate results, metadata and code.

**Authors.** Francesco Marolla, Arturo Bertero, Cristiano Vezzoni (University of Milan).
Contact: arturo.bertero@unimi.it.
